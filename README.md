## 프로젝트 소개
대부분의 도서 관련 사이트들을 보면 도서 구매 or 도서 대여를 중심의 서비스를 제공하기 
때문에 구매와 대여가 아닌 책을 좋아하는 사람들만의 일종의 도서 검색 및 개인 사용자의 
취향에 맞는 도서 추천 사이트를 만들어보고자 기획을 하게 되었습니다. 

<br>

## 개발환경
- Front-End : HTML/CSS, JavaScript, Jsp, Bootstrap, JQuery, Ajax
- Back-End : Java, Spring, Mybatis, MySQL
- ETC : Git, GitHub, Notion, Slack
